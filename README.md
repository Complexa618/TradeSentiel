# TradeSentiel

TradeSentiel is a full-stack trading and portfolio dashboard for tracking trades, account allocation, progress milestones, and related trading workflows.

## Trade Sentinel — Full-Stack MVP Complete

This repository contains the complete MVP for the Trade Sentinel application, including the backend API, frontend dashboard, supporting documentation, and test artifacts.

## Included projects

- Backend service and APIs
- React frontend dashboard
- Trade tracking and account management flows
- Progress and milestone tooling
- Documentation and automated test reports

## Getting started

1. Review the project documentation in the repository root.
2. Install dependencies for the backend and frontend as needed.
3. Start the services and verify the application workflow.
